Work hours calculator

Total the shifts in your Vcal feed.

Paste an iCalendar (.ics) URL and pick a month. The calculator reads the scheduled shifts, sums their durations, and reports the monthly total plus the average hours per week.

Why the remote Vcal URL can’t be read

This page is a single static file. When it is published it is served as plain HTML, and the browser blocks it from making a request to another site — so it cannot open https://www.amion.com/cgi-bin/ocs?Vcal=7.2179&Lo=mghpeds&Jd=10880 and download the calendar itself.

That is a limit of the page, not a problem with your link. Nothing was sent anywhere and no data was lost.

What to do instead: open the Vcal URL in a new tab, save the file it returns (it ends in .ics), open it in a text editor, and paste the whole contents — starting with BEGIN:VCALENDAR — into the paste box below. The calculator then totals the shifts exactly as it would have from the URL.

The feed is parsed in your browser — nothing is uploaded. Use https://example.com/rota.ics or press Load sample shift data to see a worked example.

Hours by week

Weekly breakdown appears after a calculation.

The parser reads every VEVENT in the feed and keeps the ones whose start falls inside the month you picked. These are the usual reasons a shift you expected does not appear.

  • Month The shift is in a different month. Only events starting inside the selected month are counted, so a shift that begins on the last day of the previous month is left out. Change the month and calculate again.
  • No end The event has no usable DTEND. Without an end time there is no duration to add up, so the event is skipped. A DURATION property is not read either — add a DTEND to the event.
  • All-day It is an all-day or date-only event. A value like DTSTART;VALUE=DATE:20250612 has no clock time, so it is ignored — it is never counted as a shift.
  • Time zone The times are in another time zone. A trailing Z (UTC) is converted to your local time zone, so a shift near midnight can land on the day before or after the one written in the file. A TZID is ignored and its clock time is read as your local time.
  • Folding The file was pasted with folded lines broken. Long lines in an .ics file continue on the next line after a space or tab. If that leading space is lost when copying, the property is unreadable and the event is skipped.
  • Cancelled The event is cancelled. STATUS:CANCELLED is not filtered, so a cancelled shift can still be counted.
  • Repeats It is a repeating shift. A single VEVENT with an RRULE is expanded into one shift per occurrence inside the selected month. Rules with COUNT, UNTIL, INTERVAL, BYDAY and FREQ=DAILY/WEEKLY/MONTHLY are supported; anything more exotic is counted once, on its start date.
